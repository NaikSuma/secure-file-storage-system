

# Secure File Storage System

A secure file storage application developed in 2025 using Java,
Spring Boot, React, AES encryption, and JWT authentication.

## Features

 Secure file upload and download
 AES-based file encryption
 Encrypted file storage and retrieval
 JWT-based authentication
 React frontend integration

## Technologies

 Java
 Spring Boot
 React
 AES Encryption
 JWT

## Project Structure

 `backend/` - Spring Boot backend
 `frontend/` - React frontend
